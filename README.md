# AI Agents

A collection of applied AI and automation research projects.

## Hybrid RAG & Stateful MCP Research Prototype

A Python research prototype covering BM25 and optional dense retrieval, reciprocal-rank fusion, optional cross-encoder reranking, LangGraph orchestration, MCP tools, context budgeting, Langfuse spans, and a 50-query starter evaluation set.

See [the project README](hybrid-rag-mcp-research/README.md) for architecture, installation, commands, tests, evaluation methodology, and limitations.

## Volume Profile Trading Agent

Paper-trading-first XAU/USD / forex / crypto Volume Profile research project. See [the project README](volume-profile-trading-agent/README.md) for setup, architecture, commands, strategy rules, limitations and safety boundary.

The MT5 adapter is read-only. No live order execution endpoint is implemented.
